# 10. Dropshipping Architecture

Design the system so it can later integrate with suppliers such as:

* Shopify-compatible suppliers
* CJdropshipping
* AliExpress-compatible APIs
* Printful
* Printify
* Other supplier APIs

Create a supplier abstraction layer rather than tightly coupling the application to one supplier.

Product data should support:

* Supplier ID
* Supplier product ID
* Supplier cost
* Selling price
* Inventory
* Supplier URL
* Product variants
* Shipping information

When an order is paid:

1. Create customer order.
2. Verify payment.
3. Reserve/decrease inventory.
4. Send order information to supplier integration.
5. Store supplier order ID.
6. Retrieve/update fulfillment status.
7. Update customer order status.
8. Provide tracking information to customer.

If a real supplier API is unavailable, implement a mock supplier service with clearly separated integration code.
